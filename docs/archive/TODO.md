# TODO 大仓库扫描机制

> 存量模式时 

1. 大仓库检测，展示多模块+文件数量+代码行数，初步让用户识别复杂度
2. 审查模式在增量和全量之后增加第三个选项，指定模块
3. 选择指定模块扫描后，让用户输入本次希望AI扫描的模块，这里可多选
4. 智能识别工作量，如果选择模块的代码行数较少则无需启动分批模式；如果上一步选择的模块包含代码行数较多的模块，智能决策是否启动分批模式
6. 启动分批模式后，提示用户正在规划分批审查计划，规划完成后展示分批任务表格给用户，让用户选择本次启动哪些批次（考虑到token额度限制，批次多时无需一次任务执行完，可分批分时段执行，分批任务可继续执行，支持中断恢复）
7. 开始执行，每个批次对应启动一个审查agent，审查指定范围内的代码

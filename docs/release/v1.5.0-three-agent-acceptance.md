## 3. 安装路径

### Claude Code

```bash
claude plugin marketplace add ataskite/cc-code-reviewer
claude plugin install cc-code-reviewer
```

安装后执行 `/reload-plugins`。

### Codex CLI / Desktop

```bash
codex plugin marketplace add ataskite/cc-code-reviewer
codex plugin add cc-code-reviewer@cc-code-reviewer
```

安装后开启新会话。Codex 插件主要面向 CLI/Desktop；IDE Extension 场景以项目级 Skill 降级说明为准。

### ZCode（Beta）

Settings → Plugins → Marketplace，添加 GitHub/Git source（`ataskite/cc-code-reviewer`），安装插件。ZCode 通过原生 `.zcode-plugin/plugin.json` 发现三个 Skill。Git 自定义 Marketplace 是 1.5.0 的正式分发路径。

## 4. 已知平台限制

| 平台 | 限制 | 影响 |
|------|------|------|
| Codex | IDE Extension 插件安装不在 1.5.0 承诺范围 | IDE 场景仅提供项目级 Skill 降级说明 |
| Codex | 结构化交互可能限制 2–3 选项 | 4 个以上选项拆成分级菜单；无多选时连续单选 |
| ZCode | 插件体系仍为 Beta | 流程和来源可能变化；Git Marketplace 为正式分发路径 |
| ZCode | `agents` manifest 字段会被记录但不会执行 | 使用通用 subagent + 共享 Prompt 注入，不依赖原生 Agent 注册 |

## 5. 完成判定

v1.5.0 支持三个 Agent 产品的前提（与计划「完成定义」一致）：

- 同一 Git 仓库能被 Claude Code、Codex、ZCode 安装。
- 三个平台都发现 scan、ignore、fix 三个 Skill。
- 三个平台都通过单 Agent scan、batch scan、ignore、fix 的 smoke test。
- 人工确认、正式扫描边界、报告合并、Feishu 职责边界没有弱化。
- 三个平台清单和文档版本均为 `1.5.0`，自动化测试可以阻止漂移。
- 共享内核没有出现三份复制实现，平台差异被限制在 runtime adapter 和 manifest。

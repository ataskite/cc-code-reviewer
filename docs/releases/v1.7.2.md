# v1.7.2 — 离线 OWASP Node/BFF Security 控制与代理身份专项

发布时间：2026-10-08（Asia/Shanghai）。支持 Claude Code、Codex CLI/Desktop、ZCode（Beta）的同仓 Git Marketplace 分发。

## 本次能力

- 固化官方 OWASP ASVS 5.0.0、Top 10:2025、API Security Top 10:2023、Node.js Security Cheat Sheet，审查运行时离线，基线哈希与来源可核验。
- 16 条稳定 Node/BFF 安全控制及冻结输入、攻击面候选索引、覆盖台账、报告校验、SARIF 控制 ID、分批与恢复门禁。
- 四条代理/身份专项：固定目标下 Host 路由控制、服务端 capability 与调用者授权、JWT 完整验证、trust proxy 拓扑和 forwarded 信任。
- Security 单 Agent 和分批 Agent 必须读取本地专项规则，不能把固定 URL、白名单键名、verify/helper 名称或代理跳数当作完整防护证明。
- src 外的 BFF TypeScript 服务端文件按信号纳入；修复范围、脱敏、报告对账、跨批控制覆盖及评测工具验收问题。

## 验证与边界

全量测试命令：

```bash
bash tests/run_all.sh
bash scripts/core/validate-plugin-manifests.sh
```

真实模型报告可离线回放：

```bash
# 历史 12 控制基线、19 个 case；不是新四控制的验证
bash tests/evals/node-security/replay-results.sh

# 新四控制、11 个 case：独立 Agent 前向评测，不是完整交互端到端
bash tests/evals/node-security/replay-results.sh --results-dir tests/evals/node-security/results/2026-10-08
```

原始记录：[历史评测](../../tests/evals/node-security/results/2026-09-24/RESULTS.md)、[新增专项评测](../../tests/evals/node-security/results/2026-10-08/RESULTS.md)。不同基线、模型档位不合并统计；原记录中的 1.7.1 是实际评测时的工作区版本，不为发布而改写历史证据。

“已检查无发现”“外部证据缺失”“静态不可验证”严格区分。未验证的 Ingress、签发配置或代理拓扑不当作安全通过，也不推测为完整攻击链。此版本不是 OWASP 认证、ASVS 全量合规或四个实际 BFF 的风险关闭证明。

## 更新与试跑

Claude Code：

```bash
claude plugin update cc-code-reviewer@cc-code-reviewer
```

更新成功后在 Claude Code 会话执行 `/reload-plugins`。

Codex / ZCode：在各自插件或 Marketplace 管理入口更新该 Git source 插件，然后按宿主要求重新加载或开启新会话。确认实际加载的插件版本为 **1.7.2**，而不只是项目目录 VERSION 已更新。发布本身不会自动改动用户机器上的旧插件缓存。

选一个真实 Node/BFF 项目，用统一 reviewer 入口选择 Security + 全量范围，保留本地 Markdown、实际代码 commit、审查范围；分批时还保留 RUN_DIR。代码审查与生产/测试环境攻击验证分开授权执行。

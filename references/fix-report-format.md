# 代码修复报告格式规范

本文件定义 `cc-code-fixer` 的 Markdown 修复报告结构。报告必须使用中文撰写；代码标识符、文件路径、命令和字段名可保留原文。

报告文件名建议使用：

```text
code-fix-report-{PROJECT_NAME}-{YYYYMMDD-HHmmss}.md
```

---

## 修复配置快照

本节位于报告头部，记录本次修复的边界与输入来源，必须包含：

- 生成时间
- 项目路径
- 修复分支
- 修复输入类型：本地 Markdown、飞书云文档、飞书多维表格或 token
- 修复输入来源：文件路径、文档 URL、Base URL 或 `base:{BASE_TOKEN}:{TABLE_ID}`
- 修复范围：全部问题、指定优先级、指定问题编号或指定模块
- 工作区策略：当前分支、新分支或 worktree
- 输出目标：本地报告、飞书云文档、飞书多维表格或组合输出
- Superpowers 状态：可用、部分可用或 degraded mode
- 验证命令列表

示例：

```markdown
| 配置项 | 值 |
|--------|----|
| 项目路径 | /path/to/project |
| 修复分支 | codex/fix-auth-check |
| 修复输入类型 | 本地 Markdown |
| 修复范围 | P0,P1 |
| 输出目标 | 本地报告 + 飞书多维表格 |
```

---

## 修复执行摘要

必须包含：

- 总问题数
- 已修复数量
- 部分修复数量
- 未修复数量
- 已忽略数量
- 待人工确认数量
- 最高剩余风险
- 本次修改涉及的主要文件

---

## 已修复问题

每条已修复问题必须按以下格式输出：

```markdown
---
**问题编号**：P1-1

**原始位置**：src/main/java/demo/UserController.java:42

**修复状态**：已修复

**修复摘要**：补充接口鉴权校验，并为未授权访问返回 401。

**修改文件**：
- src/main/java/demo/UserController.java
- src/test/java/demo/UserControllerTest.java

**验证证据**：
`mvn -Dtest=UserControllerTest test` 通过。

**备注**：无。
```

如果同一问题涉及多个文件，只列出实际修改文件；不把未修改的参考文件写入「修改文件」。

---

## 未修复问题

本节必须覆盖「未修复」「部分修复」「已忽略」「待人工确认」的所有问题。每条格式如下：

```markdown
---
**问题编号**：P2-3

**原始位置**：src/main/java/demo/LegacyJob.java:88

**修复状态**：待人工确认

**未完成原因**：需要确认批处理窗口和外部系统 SLA，当前代码无法单独判断安全重试次数。

**已尝试动作**：阅读调用链并运行现有任务测试，未修改业务逻辑。

**建议后续处理**：由业务负责人确认重试策略后再修复。
```

未修复原因必须具体，禁止只写「环境原因」「时间不足」等泛化描述。

---

## 验证命令与结果

本节记录所有执行过的验证命令。必须包含命令、工作目录、结果、关键输出摘要和失败处理。

推荐表格：

```markdown
| 命令 | 工作目录 | 结果 | 关键输出 |
|------|----------|------|----------|
| mvn test | /path/to/project | 通过 | Tests run: 42, Failures: 0 |
| git diff --check | /path/to/project | 通过 | 无空白错误 |
```

如果命令失败，必须写明：

- 失败命令
- 失败阶段
- 退出码
- 关键错误摘要
- 是否阻塞本次修复结论
- 后续建议

---

## 飞书同步结果

当输出目标包含飞书时，必须记录：

- 云文档读取结果
- 多维表格读取结果
- 多维表格更新结果
- 更新失败的记录编号
- 是否已回退为本地 Markdown 报告

如果没有启用飞书输出，写「未启用飞书同步」。

---

## 变更清单

列出本次修复实际变更的文件，并按用途分组：

- 生产代码
- 测试代码
- 配置文件
- 文档或报告

禁止列入未改动文件。

---

## 总结

必须用三到五句话说明：

- 本次修复完成了什么
- 仍有哪些风险
- 用户下一步最应该关注什么

报告末尾标注：

```markdown
**修复人**：Claude Code 修复 Agent (`cc-code-fixer`)
**报告版本**：1.0
```
